How it is built

Design

  • Page Object Model keeps every selector in one place
  • Positive, negative and edge-case coverage
  • Polling instead of brittle fixed waits

Delivery

  • GitHub Actions runs the suite on every push
  • Parallel matrix across four targets
  • Traces, video and screenshots captured on failure

Run it locally
